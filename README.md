UpIELTS 是一个面向雅思备考的离线单词与听力练习 App。它把《雅思词汇真经》和《雅思阅读 538 考点词》拆成两本独立词书，配合每日计划、艾宾浩斯复习、测试、生词本和精听播放器，帮助你把“见过”变成“记住”。

Android 7.0+
离线词库与音频
无需注册，学习记录只保存在本机
当前版本：2.9
为什么是两本词书
雅思阅读 538 考点词
收录 376 个核心考点词，按书中三类考点分级。
每个词卡带 同义替换，共 551 组，用来训练“题干词 → 原文替换词”的阅读反应。
538 原书结构是 376 个核心词 + 162 个重点同义替换 = 538 个考点；App 把 376 个核心词做成独立词卡，并把同义替换放在词卡内，数量比书里的 162 个更全，方便扩展。
208 个 538 词条从《雅思词汇真经》补充了例句。
雅思词汇真经
3674 词，按原书的 22 个真题主题编排：自然地理、植物研究、动物保护、太空探索、学校教育、科技发明、文化历史、语言演化、娱乐运动、物品材料、时尚潮流、饮食健康、建筑场所、交通旅行、国家政府、社会经济、法律法规、沙场争锋、社会角色、行为动作、身心健康、时间日期。
每个词条包含词性、中文释义、真题风格例句、记忆扩展（词根/派生/搭配等），大部分带美式/英式音标。
两本词书的复习队列、已学/掌握统计、收藏和听力进度各自独立；每日新词数量使用同一个设置。

功能
今日学习
首页只统计当前词书的待学、待复习、今日已学，不会把两本书加在一起。
「开始今日学习」直接进入当前词书，不再弹选书页。
「我的」右上角可随时切换当前词书，首页顶部切换同步。
每日新词数量可设为 5 / 10 / 20 / 30 / 40 个。
学习顺序可切换：
顺序学习：先复习到期词，再按词书原顺序学新词。
随机学习：到期词和新词一起打乱。
每组 80 词上限已解除，有多少到期词就一次排多少。
艾宾浩斯复习
按 5 分钟 / 30 分钟 / 12 小时 / 1 / 2 / 4 / 7 / 15 / 30 天 安排复习。
到期没复习的词会一直累积，最多到这本词书的总词数。
有到期词时，首页「开始今日学习」旁边会出现「复习」按钮；只复习当前词书的到期词，不插入新词。
词库与测试
词库：按主题或考点浏览，支持搜英文或中文释义；词条可收藏、标记掌握、单独学习。
测试：看词选义、看义选词、听音选词、听写拼写；优先抽已学词，答错自动进薄弱词。
生词本：独立页面，分「模糊词」和「收藏词」两块，可跨两本词书混合复习。
点击「我的 → 收藏」可直接进入生词本收藏词。
听力精听
28 篇材料：16 段 40 秒日常对话 + 12 篇 3–21 分钟 TED。
播放器支持：
播放/暂停、拖动进度、±5 秒
A-B 循环、单句循环、上一句/下一句
TED 逐句时间轴，点字幕句子可跳到对应位置播放
播放速度切换
对话材料没有逐句时间轴；TED 材料支持句子跳转。
我的
累计学习计时器：只统计单词学习和听力播放时间；在首页、我的、测试页空转，或 App 切到后台，都不计时。
学习天数、累计词数、已掌握、收藏四项统计。
词书进度可展开：
收起：书名 + 百分比。
展开：已学 / 总数、掌握数、圆圈进度、生词剩余、待复习数。
听力进度单独记录。
检查更新：通过 GitHub Releases 下载新版 APK，并调起 Android 系统安装器；学习进度保留。
其他
系统 TTS 发音，支持美音/英音与语速调节。
新词卡自动发音可关闭。
日间 / 夜间 / 跟随系统主题。
底栏四个入口：首页、词库、听力、我的。
所有词库、音频、学习记录本地存储；只有「检查更新」需要联网。
安装
打开 Releases。
下载最新的 UpIELTS-x.x.apk。
在手机上允许“安装未知来源应用”，完成安装。
首次启动会解压约 42 MB 离线资源，等几秒；以后启动不会重复。
桌面出现 UpIELTS 图标，断网也能正常背词和听听力。
更新
2.9 起支持应用内检查更新：

打开「我的 → 学习设置 → 检查更新」。
App 读取 GitHub Releases 里的 latest.json。
有新版本时下载 APK、校验 SHA256，然后调起 Android 系统安装器。
第一次更新需要允许 UpIELTS「安装未知应用」；之后直接确认安装即可。
Android 不允许普通 App 完全静默安装，系统安装确认无法跳过。
