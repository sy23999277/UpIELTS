UpIELTS
把真正会考的单词，背下来。

UpIELTS 是一个离线雅思单词与听力 App，把《雅思词汇真经》和《雅思阅读 538 考点词》做成两本独立词书，配合每日计划、艾宾浩斯复习、测试、生词本和精听播放器。

Android 7.0+ · 无需注册 · 学习记录保存在本机 · 当前版本 2.9

两本词书
538 考点词：376 个核心词 + 551 组同义替换；208 个词条有真经例句。
词汇真经：3674 词，按 22 个真题主题编排。
两本书的进度、复习、收藏独立；每日新词共用设置。
功能
今日学习：按当前词书统计待学/待复习/今日已学；每日新词 5–40；支持顺序或随机。
艾宾浩斯复习：5 分钟 / 30 分钟 / 12 小时 / 1 / 2 / 4 / 7 / 15 / 30 天；未复习持续累积。
词库/测试/生词本：主题浏览与搜索；选择、拼写、听音测试；模糊词与收藏词。
听力精听：16 段对话 + 12 篇 TED；AB 循环、单句循环、TED 字幕跳转。
我的：学习天数、累计词数、掌握、收藏；学习/听力计时；可展开词书进度。
其他：TTS 美/英音、深色模式、应用内检查更新。
安装
从 Releases 下载 APK，允许安装未知来源。首次启动解压约 42 MB，之后可离线使用。

更新
「我的 → 学习设置 → 检查更新」会从 GitHub Releases 下载新版；Android 会弹系统安装确认，学习进度保留。
